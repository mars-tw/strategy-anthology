## 最大三項改變

1. **從重金屬框改成輕礦紙軍令。** 移除深色雕花、重複紅印與金色包邊，使用單線石框、朱砂切角、灰墨正文與三相角記。手機戰鬥區刪去重複操作提示、縮減面板留白；可點控制仍 ≥44px。延續霧岩／朱砂／青瓷／藤紫識別，沒有換成另一款通用深青圓角模板。
2. **三塔分開，兵種真正放大。** 相鄰塔仍是原格位、原共鳴與射程，顯示展成三角扇形，各有塔基、AO、三色連線與細錨線連回實際格點。圖像與原格點都能正確點選／升級。角色依透明 bbox 放大，全存活動作保證至少 44 CSS px；實際手機攻城樣本最低約 **45.9px**，血條至少 36×5。灰旗盾兵使用鐵藍衍生配色與三角陣營印，友軍保留暖色與圓印。
3. **短身女將與山河沙盤統一。** 女將改短身、大色塊與清楚塔印，修正斷句；新版礦彩背景減少平草地，守城暖晨、攻城青灰。敵堡改鐵灰尖角、黑旗與焦土基座；自然河岸、石拱橋與帶箭頭行軍線讓渡口有自己的臉。道路保留真實中心路徑，加入變寬路肩與車轍。
