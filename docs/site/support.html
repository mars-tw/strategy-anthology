開始遊玩

按「接下塔印，守住松林」進入第一章，選火、冰、雷塔後確認建造。相鄰三塔可觸發共鳴；守住防線後，用同一份結晶訓練部隊反攻渡口。可隨時暫停，再用雙線軍令安排工匠與軍隊。首頁另有固定預算的「三印窄陣」演習。

Getting started

Choose the campaign button to enter Pinewood's first defense. Select fire, ice or lightning towers and confirm construction. Adjacent elemental towers trigger resonance. After defending, spend the same crystal balance to train an army and retake the crossing. Pause at any time and use Dual Orders to plan worker and army routes. The title screen also offers fixed-budget Three-Seal Drill challenges.

Saves, offline play and updates

Progress is stored locally. Use the save and legacy-import controls to export a backup. Legacy imports require a preview and convert only supported progress; they do not resume every original battle, hero or technology tree. Retaining the Village Siege identifier does not mean automatic native-save migration has been verified.

Native packages use resources installed with the app. The web version needs one complete load and an offline-ready notice. If the web version will not open offline, reconnect and let it load fully. Check the store listing for the version currently available to download.

If the game becomes stuck, pause and reopen it. Clearing app or website data or uninstalling may erase progress, so export a backup first. The developer cannot recover an unbacked-up save from a server.
