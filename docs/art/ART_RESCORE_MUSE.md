# 《三相邊境》美術重做複審

## 結論先行

**新總分：5.9 / 10（原 3.0 / 10）。**

這次不是「多畫幾棵樹」的表面修補，而是真的換了臉：地圖全幅化、主視覺立起來、三相塔開始有形體。但玩法辨識仍靠文字補洞、攻城場單位仍縮到看不見、美術風格內部打架（開場寫實厚塗女將 vs 場景微縮沙盤 vs 底部重裝金屬框）。**已脫離「半成品原型」，尚未達到「可上架完成品」。**

## 2. 先前三大致命傷逐項判定

**致命傷一（共用深藍綠模板身體）：部分解決。**
證據：三張圖頂部皆改為暖紙色底＋宋體感標題＋紅色結晶數，深藍綠殼已消失（截圖1、2、3 頂欄一致）；截圖2 的女將紅披風＋山水全幅構圖是別款沒有的臉。未解決部分：底部面板仍是深色重雕花金屬框（截圖1「三相防線」、截圖3「前線軍令」），拿掉標題後仍像任何一款國風手遊的通用框體；章節 1–6 圓點、右上深色矩形按鈕仍是舊模板語彙。

**致命傷二（35–45% 純色死區、戰場被壓成扁帶）：已解決。**
證據：截圖1、3 戰場約佔全高 47%（約 y 17%–64%）、寬 100%，容器內無深綠填充；截圖2 上半 58% 為全幅場景＋人物，不再是「地圖截圖加黑盒」。此項通過先前驗收第 2 條。

**致命傷三（遊戲性圖像全是文字與色塊）：部分解決。**
證據（已改）：截圖1 三塔有實體造型——火焰形、冰錐形、紫雷紋塔身，卡面（火印塔／冰印塔／雷印塔）有圖示且選取態以紫色外框＋放大呈現；截圖2 右下火／冰／雷為寶石形圖示而非單字。證據（未改）：截圖1 三塔擠在同一格相互遮擋，只剩雷塔完整可見，火、冰塔被壓成背景；截圖3 衛士／弓手／術士在場上仍是小人點，「兵營」「結晶補給」靠 11px 級文字標籤，敵據點（截圖3 右上）仍是紅屋頂建築，與我方松林守望軍（截圖1 右下）造型語言未分家。

## 3. 新出現的問題

1. **三塔重疊部署（截圖1）**：三塔同格疊放、无各自落地陰影與塔位圈，是部署邏輯或美術層級事故，比「塔太小」更傷——玩家會以為是合成錯誤。
2. **風格三國鼎立**：截圖2 女將為半寫實厚塗，場景為微縮沙盤水彩，UI 為重裝雕花金屬，三者像三款遊戲的拼貼；女將腰間牌飾、槍刃邊緣有明顯生成式繪圖的含糊筆觸，近看露餡。
3. **道路與河流仍是色帶**：截圖1 土路邊緣銳利等寬、截圖3 河流為等寬直帶（約畫面寬 12%），未達先前「邊寬變化 ≥20%」要求；截圖3 虛線行軍路線仍無箭頭。
4. **攻城章節無色溫差**：截圖1 與截圖3 同為晨光暖綠，守城／攻城截圖並排分不出玩法，切換感不存在。
5. **底部框喧賓奪主**：雕花邊框＋四角紅印佔面板面積近兩成，截圖3「補給運轉中」等淺色小字壓在深框上對比不足。

## 4. 下一輪最該做的 5 件事

1. **修塔位呈現**：每塔獨立塔基圈＋橢圓 AO 陰影，禁止同格疊放；三塔相鄰時以三色光暈連線取代文字「+30%」，部署前顯示射程圈。
2. **單位放大與敵我分家**：場上單位高度 ≥44px，我方披風色塊、敵方鐵灰高盔；敵據點改鐵灰尖角＋黑旗＋焦土基座，與我方紅瓦建築永不共用輪廓。
3. **道路河流自然化**：路寬變化 ≥20%、加路肩與車轍；河寬 120–200px 變化、加沙岸蘆葦與流光，橋做石橋弧面。
4. **統一風格並重做開場主視覺**：以場景的微縮沙盤水彩為全作基準，女將改同風格 2.5 頭身或保留厚塗但讓三相塔入前景；修復生成痕（手部、牌飾、槍刃）。
5. **UI 減重與章節色溫**：底部框雕花減半、改結晶切角形；守城暖晨光、攻城青灰陰天；交付時附縮圖 64px 辨識與去文字測試實測紀錄（靜態截圖無法驗證動態，此項本輪未評）。

## 5. 專屬視覺識別：**是（強度中等）**

理由：去掉標題後，紙色頂欄、山水沙盤地圖、三色結晶塔、紅披風女將四項組合，在同帳號的深色科幻／像素／兒童明亮色作品中無一重複，商店並排可分。但識別主要由開場圖與地圖承載，UI 框體仍可移植到任何國風遊戲——識別是「內容的」，還不是「系統的」。
