# R2 來源技法與實際採用

2026-10-16。唯讀研究本 repo 既有 MIT 來源，承接 `docs/ART_STUDY.md`；沒有下載或改寫其他 repo。

- village-siege 的 4×6 atlas：透明留白是定位契約，不是角色身高。R2 計算每格 bbox、全存活動作最小高度，整張圖集維持固定倍率與原 pivot。這讓手機可見身高守門有依據，也不必重畫已驗證的攻擊動作。
- tower-defense config／rules：共鳴由原格距與元素判定，並非看起來靠近就有。三塔展開時明示實際格點錨線，射程從原格點畫，點選兼容舊格與顯示塔身；保留原計費與 trinity 測試。
- 原地景 materials.webp：以材質填充變寬的道路多邊形、保留中心路徑，路肩與車轍補深度；水面沿變寬岸線裁切。新橋接在兩個合法渡點，不發明新通路。
- R1 礦彩塔／建築：保留左上暖光與三相剪影，女將改短身大平面，框體退為輕礦紙。從 `ART_RESCORE_MUSE.md` 直接對應畫風三分與底框過重問題。

本次沒有 3D 資產，父層規則的 Blender rig／材質重工不適用 2D PNG／WebP；模型精確 slug 以本次使用者允許工具名的規格為準。全程無外部派工。
