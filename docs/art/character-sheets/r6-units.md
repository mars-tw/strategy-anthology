# R6 三職業設定與動作契約

先交 `r6-units.png` 的正／側／背與表情，再依同一識別產出本輪三套圖集。出貨時的緊湊服裝變體以 `../r6/sources/warrior.png`、`archer.png`、`mage.png` 為正本：衛士朱紅圓盾短劍、弓手青瓷兜帽完整短弓、術士藤紫短披襟與短分叉杖。長下襬收至膝附近，讓腿部交替可見；肖像保留同臉、頭飾、色票與武器。指揮官是敘事立繪，不是新增可操控兵種。

設定圖下緣的建築是生成外形草圖，不作高度量測正本。出貨尺寸以 `../SCALE_SPEC.md`、畫面量測JSON及原尺寸商店截圖交叉驗證，不把草圖當成已通過比例的遊戲畫面。

三套圖集各4×6，依序為待機／行走／攻擊／受擊／死亡／施法。行走有交替腿，攻擊第三格是命中；命中結算仍在引擎0.20秒，沒有改傷害或AI。每一整張原圖用共同0.72倍縮放；衛士、術士新站姿受擊strip各自用一個共同因子對齊該角色中立身高，不逐幀拉大蹲身。固定腳底250，不把倒地幀重新拉成站姿高度。輸出保留格間空白、完整武器，來源列界以實際透明間隙尋找，避免256px假設切斷靴子。

手機390寬中立身高48 CSS px。所有存活的待機、行進、攻擊、受擊、施法外框高度至少40px；倒地自然降低，未用單幀放大冒充動作。左向為鏡像衍生，不稱為新方向原畫。工匠、灰旗兵與甲犬的受擊／倒地保留R5姿勢；甲犬新增三種各四格行軍姿勢，旗桿不計軀幹身高。

色彩與alpha結果：`../ASSET_MANIFEST_R6.json`；64px無字縮圖：`../r6/thumbnails/unit-lineup-64.png`、`enemy-variants-64.png`。新圖都使用同一左上光、暖墨輪廓與短冷紫接觸影。
