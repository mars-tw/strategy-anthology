# R5 開源美術技法研究與應用

2026-10-18，唯讀研究，沒有複製外部美術。

- Wesnoth 官方 Creating Unit Art：https://wiki.wesnoth.org/Creating_Unit_Art 。角色需放回多種地形檢查，不能只看透明底。本輪保留灰底見證與河岸／草地實載圖。
- 官方 Create Art：https://wiki.wesnoth.org/Create_art 。動畫幀與地形變體分開管理。本輪保持明確 frame map，三甲犬配件變體不取代真正步行姿勢。
- 官方 terrain-graphics.cfg：https://github.com/wesnoth/wesnoth/blob/master/data/core/terrain-graphics.cfg 。橋身與橋端接地分層啟發本輪橋影／嵌岸台階，不把橋當河面上的獨立橫桿。
- 官方 Choosing your palette：https://wiki.wesnoth.org/Choosing_your_palette 。色盤與陣營影色須一致。本輪朱紅盾／青瓷弓／藤紫杖對鈷藍敵軍，保留形狀差異，避免只靠顏色。

上述是技法參考；不引入 Wesnoth 圖像或授權負擔。遊戲既有礦彩與軍令紙框維持為金標。
