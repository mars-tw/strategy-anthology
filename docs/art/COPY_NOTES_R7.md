# R7 文案回讀

本輪沿用核心規則 mode 2，直接套用並事後記錄。版本、價格與規則數值不改。

| 原句 | 原因 | 改成什麼 |
|---|---|---|
| 確認建造（已點選場上塔時仍相同） | 操作實際為升級，與買不起塔卡同時出現會誤判 | 已選場上塔時顯示「升級 · 60」；滿級顯示「已達最高等級」 |
| 確認建造（資源不足仍亮起） | 按鈕與可用資源矛盾 | 無預覽或不足時停用；不足預覽顯示「結晶不足」 |
| 火印塔 100 結晶（無無障礙資源狀態） | 看不出不可購買的原因 | 保留原價，aria-label 加「結晶不足」；紅價與灰圖同時呈現 |

沒有增加宣傳承諾、角色背景或玩法數值。角落共鳴標示保留實際 +30%／0%，刪除重複符號。原英文名稱與既有章節文案保留。
