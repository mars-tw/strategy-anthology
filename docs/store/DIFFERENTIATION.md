# 整合後七款陣容的區隔

PREPARED。2026-10-16。Apple 4.3 風險：高。比較範圍為本次工作單指定的陣容，其他六款的方向依工單，未在本輪實玩、讀取最新商店狀態或宣稱市場唯一。

三相邊境的核心循環是「元素相鄰守城→同一錢包育兵→雙線軍令反攻→收復地轉守城」。玩家不從模式清單選兩款遊戲，而是推進六章主線。

原《無盡塔防》與《村莊攻防》不再各自列為整合後陣容中的獨立新品。三才陣實際影響攻城可用兵種，攻城結果實際解鎖同地形守城；這些是程式與測試可驗證的產品整合，不只更名或截圖更換。
