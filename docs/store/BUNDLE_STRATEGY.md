# 商店紀錄與 Bundle ID 建議

PREPARED，沒有操作 App Store Connect 或 Google Play。

建議沿用《村莊攻防》的既有 App 紀錄（工單退件檔中的 App ID **6819988533**），將其更新為《三相邊境》，原 Bundle ID 保留不變。理由是本作的主線、聚落角色與攻城操作延續村莊；塔防成為守城章節，與既有策略受眾連貫。更新既有項目也比較容易明確說明兩款合併、減少重複提交，並保留舊玩家的更新路徑。

本 repo 的 0.1.0 是整合網頁版本，不能當成既有 App 的降版送出。原生行銷版本可先規劃 2.0.0，但必須由商店線確認正式紀錄與 build number 後定案；本輪沒有變更任何商店版本。

本輪來源文件沒有可核對的村莊 Bundle ID 字串，未讀取外部 native-kit 或商店。**確切識別字待打包線從既有正式紀錄確認，不猜測也不自行建立。** App ID 與 Bundle ID 不是同一個欄位。

不建議另建第三個紀錄後又保留兩個原作同時重送。待帳號持有人決定舊《無盡塔防》紀錄（App ID 6819988196）如何保留／停售，再由獲授權的商店線處理。本線路沒有權限改商品可用性或撤下 App。

舊玩家更新風險：目前網頁版本透過使用者貼存檔碼或章節 JSON 匯入。原生 WebView 若沿用既有 Bundle ID，原資料仍可能留在舊儲存命名空間，但本輪未驗證原生儲存搬遷，不能直接宣稱自動保留成功。正式更新需做舊版→新版實機升級、匯出／恢復與 storage namespace 測試；無法自動搬遷時，先發行提供匯出入口的過渡版，由商店線另案執行。
