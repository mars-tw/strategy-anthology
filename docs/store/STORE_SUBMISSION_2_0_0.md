## 新版說明

《村莊攻防》與《無盡塔防》整合為《三相邊境》，沿用村莊攻防的 App 紀錄。

- 六章交替守城與攻城，共用進度、結晶與兵種解鎖。收復的渡口與石脊，會成為後續防線。
- 火、冰、雷塔相鄰可觸發共鳴；攻城時用雙線軍令，同時安排工匠補給與軍隊行進。
- 戰後選擇保留工事或拆取結晶。守城前可預覽堵隘與放水，決定敵軍路線。
- 新增五題固定預算的「三印窄陣」。戰報可比較首波實數，並用獨立預算重打另一分支。
- 調整道路縱隊、塔位標籤、輔助關閉時的地形辨識，以及戰報的結果呈現。

進度保存在本機，可自行匯出備份。舊作紀錄需預覽後匯入，僅換算支援的進度；沒有保證所有舊戰局、英雄或科技可接續。原生舊版升級的自動存檔搬移仍需實機驗證。

Village Siege and Endless Tower Defense are consolidated into Trine Frontier under the existing Village Siege record.
