1. **攻下一座，留下一塔**：石脊攻城勝利頁 → 留上游火塔／留城門火塔／拆取90結晶。原有取捨保留。拆晶收據的入帳算式不變，下面的目前餘額跟著共用錢包更新；建塔後及重載後都能對帳，戰報首頁也可查。交戰預設顯示具名塔、目標與實扣，點「明細」才看完整公式。回顧先講攔下數、耐久、傷害與命中的變化，相同列自行展開。
2. **戰前改地形**：守城第一波前 →「戰前工事」→ 預覽堵隘／放水 → 確認施工 → 排塔。塌石木柵使用完整既有原畫，放大到120 CSS px以上；紅叉在本體旁。放水改用完整水岸原畫及同源水面遮罩；移除圓形青色外框及跨圖塔位錨線。河面道路以柔邊接岸，保留原畫橋樑。北路連拍會使用真正能打到新路的布陣。
3. **三印窄陣**：首頁 →「三印窄陣」，或戰前工事 →「先試三印窄陣」。五題維持原預算、原邏輯塔位、原路徑及原勝敗。近鄰座標在整張地圖一致展開，路面、單位、塔體與底座共用投影；塔不再放在文字欄。射程環以塔基為中心，直接點塔位可選位；上下欄只留具名文字及引線。未確認的預覽先確認或取消才能開戰。甲犬保留真四步幀，以顯示排隊與避讓減少遮擋，不改模擬速度、血量或傷害。小螢幕結算收起最後命中欄，保留塔位空間。
