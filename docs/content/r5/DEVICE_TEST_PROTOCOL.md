# 待補裝置與玩家測試

BLOCKED：本機只有無頭 Chromium 觸控模擬，沒有連接實體 iPhone／iPad，也沒有真人或親子受測者。Muse ≥8 分需後續獨立複審，本輪沒有外部派工或自評達標。

需要一台 iPhone、一台 iPad（含直橫向操作），以及至少一名未玩過的新玩家；親子理解若要驗收，另需家長與兒童自願參與。實機應使用已下載的離線包，開啟飛航模式重載、完成三題並重開檢查紀錄。

請玩家直接指出：留下的冰塔名稱／位置／開火；水域在哪段減速；火、冰、雷各自能否打到新路；三題哪幾格有塔、哪些格故意留空。不要先告知答案。逐項記錄操作、誤判、完成時間與裝置／系統版本；未做的項目保持 BLOCKED，不填成零或通過。

效能需另用沒有其他工作負載的實機量測。此輪實際 RAF 三跑僅是同機並發載參考，不代表 iOS 效能或乾淨機證明。
