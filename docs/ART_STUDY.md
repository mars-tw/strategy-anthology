# 原作美術研究與本輪採用

EXECUTED。研究對象為本次唯讀的兩個 MIT 來源遊戲，未使用外部生成或第三方商業遊戲素材。

村莊原作的 frontier 圖集以石牆、木梁、橘瓦與湖藍旗幟建立共同語言；自然物採俯視體積、亮面草葉與接地陰影。角色 4×6 動作列與六個獨立面向讓肢體姿勢改變，不靠整張圖縮放晃動。塔防原作的元素辨識與局部鄰接關係，適合以小而明確的火冰雷印記、共鳴連線呈現，不需要把神話角色原畫混入中世紀聚落。

本輪因此統一採用村莊地形／建築／角色，以同一座石塔承載三種元素，搭配原生繪製的共鳴光鏈和六章行軍線。沒有新點陣圖、單純換色的假地圖、3D 方塊素體或整張角色圖晃動；角色視覺與模擬位置分離，attack impact、hurt、death 使用各自動作格。渡口河面不可當行軍目標，實際過河經上下橋，不讓河流只是一張背景貼圖。

`evidence/art-analysis.json` 分析 28 張原圖：每個動作列皆有四個不同像素姿勢，真幀契約通過。色彩是 alpha>128 的既有像素參考量測，不是實體裝置或人工三視圖裁決。**17/28 張未同時滿足 skill 的亮度／飽和度參考閘**，以護甲、衣料的低飽和比例為主；沒有偷偷調低門檻、修改來源或把未通過寫成通過。
