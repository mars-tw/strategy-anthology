# 三相邊境整合結果

2026-10-16。版本 **0.1.0**，英文 **Trine Frontier**。本機網頁整合 EXECUTED；可執行驗證依 `evidence/verification.json` 的最終結果；商店草稿 PREPARED。只修改 strategy-anthology，沒有 push、部署、操作商店、外部派工、讀取秘密目錄或開啟可見視窗。

## 設計與完成範圍

一條主線六章：**松林守城→渡口反攻→渡口守城→採石場反攻→採石場守城→高地決戰**。玩家是同一支松林守望軍的指揮官；火冰雷守城得到的結晶與三才印記解鎖攻城兵種，攻下的土地成為下一章守城地形。入口直接接主線與第一種玩法，不是兩款遊戲的啟動選單。

- **VERIFIED：原生模組整合。** 移植塔防的 config／rules，以及村莊的 combat／fieldOrders。實際 runtime 使用來源共鳴、塔資料、兵種傷害與雙線軍令；來源檔案與關鍵測試保留原樣，不用 iframe。新模擬器、主線、HUD、存檔、輸入與繪圖均在本 repo。
- **VERIFIED：共用進度。** 同一結晶錢包、章節順序、三種可用軍事兵種、三才印記與中途戰局；重要操作、每三秒與背景／關頁保存。匯入有預覽、確認、原檔封存、一次性來源獎勵及匯入前備份；配額失敗不假稱已儲存。
- **VERIFIED：統一外觀與操作。** 兩模式共用村莊原畫、字型、色盤、行軍線、元素標記、短音、設定／暫停／返回。取消、觸控中斷與旋轉不扣建造費；震擊須命中才扣結晶。渡口有實際橋樑路線，河面不能直接指定為行軍目標。
- **EXECUTED：移除重複系統。** 不帶入兩套模式大廳、設定、教程、排行榜或抽卡／多貨幣。保留最好辨識的三才陣、工匠返程補給、軍隊指揮與雙線暫停規劃。新戰役只有三種玩家軍事兵種，沒有宣稱七兵種、科技、多人大廳與自由戰役已全部移植。

詳細規格：[MERGE_DESIGN.md](MERGE_DESIGN.md)，逐項計畫：[OPTIM_PLAN_MERGE.md](OPTIM_PLAN_MERGE.md)。
